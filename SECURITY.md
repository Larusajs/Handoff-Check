# Security policy

This project is pre-release. There are currently no supported stable releases.
Only synthetic input should be used in public reports.

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature if it is enabled for this repository. If unavailable, open a
public issue requesting a private reporting channel without exploit details or
sensitive input. Do not post credentials or private manifests.

Verification reads local JSON files and does not resolve source URLs or execute
manifest content. A passing check does not authenticate a manifest, establish
authorization, validate free-text meaning, or grant permission for an action.
