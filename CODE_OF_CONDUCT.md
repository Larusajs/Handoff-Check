# Code of conduct

Be respectful, constructive, and patient. Welcome contributors with different
backgrounds and experience levels. Critique ideas and code, not people.

Harassment, discrimination, threats, doxxing, and persistent disruptive behavior
are not acceptable in project discussions, issues, reviews, or other project
spaces. Maintainers may edit or remove content and restrict participation to
protect contributors. Enforcement should be proportionate to the behavior.

Report public incidents to repository maintainers using GitHub moderation tools.
For private incidents, request a private channel without posting personal details.
